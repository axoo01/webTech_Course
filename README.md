# Spring Boot REST API Assignments

All questions are separate Spring Boot projects (Q1 to Q5 + Bonus).

## Projects
- q1-book-api → Library Book Management
- q2-student-api → Student Registration
- q3-menu-api → Restaurant Menu
- q4-Ecommerce-api → E-Commerce Products
- q5-task-api → Task Management
- bonus-q-api → User Profile (extra)

## How to Run
For any project:
1. `cd qX-xxx-api` (replace X with number)
2. `./mvnw spring-boot:run` (or use IDE run button)
3. Test endpoints with Postman at http://localhost:8080/api/...

## Testing Proof
Screenshots of successful Postman tests are in:  
`Spring/api/Screenshots/` folder (one subfolder per question).

Examples:
- Spring/api/books

...
